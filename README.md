# AFROTECH 2026: GitHub Copilot CLI Lab

A 30-minute hands-on workshop for AFROTECH 2026 in Houston. You'll play a quiz game, discover areas of improvement, and use **GitHub Copilot CLI** to understand the code, investigate, test, and improve it.

## Get Started

1. Click **Code → Codespaces → Create codespace on main**, or open this link:
   [Open in GitHub Codespaces](https://codespaces.new/darrellbooker/afrotech-copilot-cli-lab)
2. Wait for setup to finish. Python, pytest, and Copilot CLI install automatically.
3. Open [`lab-ghcp-cli/README.md`](lab-ghcp-cli/README.md) and follow the steps.

> 💡 You'll need a GitHub account with access to GitHub Copilot. Copilot Free works.

## What's Inside

| Path | What it is |
|---|---|
| `lab-ghcp-cli/` | The quiz game and the lab instructions |
| `lab-ghcp-cli/reset.sh` | Optional. Returns the lab to its starting state |
| `.devcontainer/` | Codespace setup |
